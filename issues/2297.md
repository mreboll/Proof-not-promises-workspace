# #2297: Add ExcludeFromCodeCoverage attribute to generated code.

Fuente: https://github.com/MessagePack-CSharp/MessagePack-CSharp/issues/2297

#### Is your feature request related to a problem? Please describe.
MessagePack generated code is not decorated with ExcludeFromCodeCoverage attribute.

Because it is very hard to write good coverage for generated MessagePack code, it may skew coverage numbers, especially on large projects with a lot of generated code.

#### Describe the solution you'd like
I would like all generated code to be decorated with ExcludeFromCodeCoverage attribute.  I do not feel like a setting is needed, but setting would be fine to have too.

#### Describe alternatives you've considered
There are no alternatives, it is close to impossible to write good coverage for generated code as it covers many edge cases.

### @b-kurczynski-dl

Hi Sergey,

I found your ticket as probably I faced the same issue you did. If you use dotnet-coverage to collect the coverage you might adjust your [settings XML](https://learn.microsoft.com/en-us/dotnet/core/additional-tools/dotnet-coverage#settings). I applied the following change and MessagePack's generated classes stopped to be counted:

```
<Configuration>
    <CodeCoverage>
        <Sources>
            <Exclude>
                <Source>obj\\.*\.g\.cs$</Source>
            </Exclude>
        </Sources>
    </CodeCoverage>
</Configuration>
```

Maybe it helps you too.

I'd be happy to send a PR for this if it's welcome.

What I have in mind: add `[global::System.Diagnostics.CodeAnalysis.ExcludeFromCodeCoverage]` (and possibly `[global::System.CodeDom.Compiler.GeneratedCode("MessagePack.SourceGenerator", <version>)]`) to the types emitted by the templates under `src/MessagePack.SourceGenerator/Transforms/` (formatters, string-key formatters, enum/union formatters, resolvers), then update the verified snapshots. No setting. The generated files already carry `// <auto-generated />`, but coverlet doesn't exclude based on that by default, so the attribute is what coverage tools actually honor.
